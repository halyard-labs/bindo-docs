---
title: Business knowledge
description: Add FAQs, services, pricing and policies that can support replies.
---
Create a short entry for each useful fact or policy. Choose **FAQ**, **Service**, **Pricing** or **Policy**, then write a clear title and the answer your team would give.

Draft entries are private working material. Only **Published** entries can support generated replies. **Archive** withdraws an entry. A review date makes it unavailable from the start of that date in Australia/Sydney time.

The pilot supports 100 entries per workspace, up to 8,000 UTF-8 bytes per entry. Edit existing entries when you reach the limit; archived entries still count.

Bindo selects up to six relevant published entries using keyword matching. It does not crawl websites or import Google Drive automatically. Drafts retain the versions of sources they used, so staff can inspect the actual information behind a reply.

### When facts change

Changing knowledge or assistant settings invalidates existing generated approvals. Generate a new draft against the new information. Sources show what the model was given; staff still need to check that each statement follows from those sources.
